## 4. KVMem 环：五开关 + 池算术 + 判据

### 4.1 五个环境变量（**缺一不可，没有 CLI 参数**）
```
NINFER_KV_WINDOW=16384        # 常驻窗口（也是"环是否启用"的判据）
NINFER_KV_RETRIEVE=8192       # 检索预算 —— 缺它 = 静默答错（全绿日志 + 错答案）
NINFER_KV_RING=1
NINFER_HOST_PAGEABLE=1
NINFER_KV_REUSE_HOSTBACKED=1
```
### 4.2 池算术
```
池页数 = 常驻窗口/64 + 预填块/64 + 余量(8)     例: 16384/64 + 1024/64 + 8 = 280 页 = 17,920 token
宿主层: 每 1 token 逻辑上下文 ≈ 25 KiB 主机池    ⇒ 256K≈6.6 GiB
启动守卫: 主机池页数 + 设备池页数 ≥ 逻辑上下文页数（不成立则启动期拒绝，不静默降级）
```
### 4.3 启动必须看到的行（复现白皮书 §8.3）
```
[ring] content scoring ON by default (the ring is configured): …
INFO  engine ready | <model> | total <N>s | weights <X> GiB | CUDA sync auto
INFO  capacity | KV 17,920 tokens, k8v4, explicit | pages 280/4,096 | runtime <X> GiB | free <Y> GiB
```
### 4.4 判活（**官方明确**）：`/v1/models` 返回 200 **≠** 能服务（worker 死后照样 200）⇒ **必须真发一条请求**。

## 9. 第二轮新增 · 文档类（`docs/02` `03` `04` `08` `09` + `判据.txt`）

### 9.1 `docs/02-排错手册`（症状 → 判据 → 处方）

**三行诊断法**（90% 的问题在这三行）：
| 日志行 | 它在说什么 | 正常长相 |
|---|---|---|
| `capacity \| KV … \| pages X/Y \| runtime …` | 池有多大（X=物理池、Y=逻辑上限） | 本档 `pages 152/152 \| runtime 1.54 GiB` |
| `[ninfer] reuse host-backed: on/off` | **复用门控**是否打开 | 必须 `on` |
| `req#N done \| … \| cache N (P%)` | 这一问复用了多少 | 首问 `0 (0.0%)`；同会话续问应 ≈`99.9%` |

**关键条目**：`FATAL … needs a Host KV tier…`（**是特性不是故障**，按消息抬 `--host-kv-mib`；参考 65536⇒≥2048 MiB、262144⇒≥8192 MiB）· `requires --max-concurrency 1` · **`HTTP 429 不是过载**（是连续 8 次 OOM 后把待处理请求按"过载"拒掉）· **首问 40k ≈19–22 s 正常，第二问也这样就查复用** · **复用没生效最常见的坑 = 客户端把同一段全文当"独立单请求"重发**（复用靠"会话推进"）· §2.4 静默错误三连（漏 `NINFER_KV_RETRIEVE` / KV 档换错 / 长会话"每轮只回一行计划"）。

### 9.2 `docs/03-调优方案`（★ 三个旋钮 + 两条机理）

- **只调三个数**：`NINFER_KV_WINDOW`（常驻窗口）· `NINFER_KV_RETRIEVE`（检索预算，**调 0 = 中段看不见且零报错**）· `--host-kv-mib`（主机层）。池自动：`窗口/64 + prefill块/64 + 8`。
- **§7 KV dtype 机理（★ 直接关系我们的参数选择）**：值平面的 absmax scale 粒度 —— `fp8`=**整行 256**、`int8`=G64、`rk*`=G32 ⇒ 值激活带离群通道的制品会"**只出 2 token 就 EOS 且零报错**"；**`k8v4` / `nvfp4` 的值平面是 G16 ⇒ 免疫**；**键平面无罪**。阈值夹在 **232✅ / 432❌**。**警告：不要用"位宽更高 ⇒ 更安全"推断**（实测 8 bit 的 fp8 崩、4 bit 的 nvfp4 正常）。
- **§8 自旋风险** ⇒ 见 §10.2 立项。

### 9.3 `docs/04-卡死与循环的防治`（★ 14 种症状全谱 + 处方）

## 13. ⭐ 第二轮新增的"对我们有用"发现（CODE 归纳，供 TELE 复核）
