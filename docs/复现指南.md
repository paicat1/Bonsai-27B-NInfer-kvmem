# 复现指南 —— Bonsai-27B-NInfer-kvmem（RTX 5080 / sm_120a）

> **口径（先看这条）**：本仓**不含**引擎成品与模型制品（体积原因）。
> 这里的"复现" = **照本仓材料把引擎重新编出来**，**不是"下载即用"**。
> 想"看过程" → §六 过程索引；想"自己跑起来" → §一–§五。

## 二、取材料（**两步**：源码 + 脚本）

> **注意**：本仓**两个分支各管一半**，复现要**两样都取**：
> - **`main`**：构建脚本 / 复现材料 / 文档 / 启动器 —— **没有**引擎源码（`src/` 为 0 文件）
> - **`engine-main`**：引擎源码树（`CMakeLists.txt` / `src/` / `include/` / `tests/`）—— **没有** `build/` 构建脚本
>
> 两分支有**同名但内容不同**的文件（`README.md` / `NOTICE.md` / `docs/`）⇒ **不要混检到同一目录**，否则会互相覆盖。

| 步骤 | 命令 | 拿到什么 |
|---|---|---|
| ① 项目层 | `git clone -b main <本仓地址> proj` | `build/`（构建脚本 + 必改路径清单 + 产物清单）、`docs/`、启动器 |
| ② 引擎层 | 进 `proj` 后：`git worktree add ../engine-tree engine-main` | 引擎源码树，**已含本项目全部补丁，直接可编** |

- **为什么两步**：源码在 `engine-main`、脚本在 `main`——**任一分支持有另一分支缺的那半**。
- **同名"变脸"警示**：`README.md` / `NOTICE.md` / `docs/` 在两分支**同名但内容不同**。用 `git worktree`（各自独立目录）**不会**互相覆盖；若在**同一目录**反复 `git checkout` 切换分支，这些文件会**变脸**（内容被换掉）。
- **我们改了什么**：`build/patches/`（3 个补丁 + 说明）；**整个过程**见 `main` 的提交历史 与 `docs/Bonsai-27B-NInfer-kvmem-项目构建史.md`。

## 三、改路径 → 构建

1. **改路径**：见 `build/README.md` **§四「必改的绝对路径清单」**——8 个脚本里写死的本机路径（vcvars / CUDA / vcpkg / `SRC` / `BUILD`），照表改成你自己的。
   （我们**故意不做参数化**：路径是机器特定的，写死更显式、更好调试；理由与"防漂移"约定都写在 §四。）
2. **全图构建**：`cmd /c s6_1208a.bat` → 产物 `<BUILD>\apps\ninfer-serve.exe`（**+ 同目录 DLL，必须放一起**）。
   （旧基线 20261003 路径：`s6_configure.bat` → `s6_build.bat` / `s6_build_runtime.bat`）
3. **单测**（可选但建议）：`powershell -File s6_1208a_test.ps1` → 期望 **退出码 0 且无输出**（该测试**成功静默**；53 项断言全过才返回 0）。
4. **产物落位**：把 exe+DLL 拷进正式目录（本机 = `engine\self-built-20261008\`）；**不要**留在构建中间目录。

## 五、起服与判活

| 入口 | 说明 |
|---|---|
| `启动器.bat`（GUI） | 选参数 → 预览命令 → 起服；顶部「引擎」可切 官方 / 自编 |

**⚠️ 判活纪律（本项目踩过的坑）**：`/v1/models` 返回 **200 ≠ 能服务**——必须**真发一条请求**（`/v1/chat/completions`）看有没有正文。**KVMem 池小 + 上下文大时，HTTP 200 也可能静默答错。**

**关窗 = 停服**：起服后那个控制台窗口就是服务本体，关闭即停止。

## 七、常见坑

| 症状 | 原因 / 处置 |
|---|---|
| MSVC `c1083 cstddef` | 没先 init `vcvars64.bat`（环境问题，非代码） |
| `.bat` 乱码 / 变量失效 | `.bat` 注释含中文（cmd 按 OEM/ANSI 解析）——**注释一律 ASCII-only** |
| `git push` TLS 握手失败 | 代理链路抖动；`smart_push` 会自动降级 **OpenSSL → 直连** |
| 构建产物留在 `.temp\` | 中间物 vs 成品要分开：成品拷进正式目录（`build/README.md` §七） |
